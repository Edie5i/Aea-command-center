# **App Name**: Firebase Flow

## Core Features:

- Instructional UI: Display a clear set of instructions based on user prompt, broken down to simple copy and paste actions to assist users when integrating Firebase into their projects.
- Instruction Generation: Integrate an AI tool which takes Firebase config object and then outputs a clear set of instructions to complete the integration process.
- Copy to clipboard: Implement copy-to-clipboard functionality for the Firebase config object and the AI-generated instructions, facilitating easy transfer to the user's project.
- Firebase Config Input: Incorporate a form or text input field for users to directly paste their Firebase config.
- Workflow Management: Step by step integration workflow that makes it as easy as possible for a non-expert to add Firebase functionality to their web application.

## Style Guidelines:

- Primary color: Saturated sky blue (#6FD6FF), to give the feeling of clarity and transparency.
- Background color: Light gray (#F0F2F5), which will keep the UI neutral and not distract the eye from the integration steps.
- Accent color: Muted turquoise (#70AFA3) to provide subtle contrast.
- Body and headline font: 'PT Sans', a sans-serif, giving a balance between modernity and readability.
- Use simple and direct icons that correspond to each step in the instructions, clarifying the functionality for users.
- Layout: Use a minimalist approach, dividing content into sections to not overwhelm users with the integration steps.
- Subtle animations, when transitionin between steps.
