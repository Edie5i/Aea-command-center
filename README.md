# Aea-command-center

**AEA** (Automatización con Estructura para Agentes) es un centro de mando para automatizaciones con agentes de IA.

## Descripción

Este repositorio sirve como punto central para organizar, configurar y desplegar automatizaciones basadas en agentes de inteligencia artificial. Actúa como "torre de control" desde la cual se coordinan flujos de trabajo automatizados impulsados por IA.

## Estructura del repositorio

```
.
├── .github/
│   └── workflows/    # Workflows de GitHub Actions para CI/CD
└── README.md
```

## Estado del proyecto

Este proyecto está en una etapa inicial. La estructura y funcionalidades se irán agregando progresivamente.
